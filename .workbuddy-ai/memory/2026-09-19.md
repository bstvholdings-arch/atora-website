- **奖项**：`awards` + `award_media` 两表。前台 `AwardsSection.tsx`（Grid/Timeline 切换 + 拿奖故事弹窗）；详情页 `/[lang]/about/awards/[slug]`（独立 SEO + `CreativeWork`/`BreadcrumbList`）；后台 `/admin/awards`（CRUD + 多图上传排序设封面）。

## 踩坑与修复
1. **Supabase 直连主机名失效**：`db.umnnzabvivodfqzyfnco.supabase.co` → `ENOTFOUND`。`.env` / `.env.local` 的 `DATABASE_URL` 已切到连接池 `aws-0-ap-southeast-1.pooler.supabase.com:5432`（原值以注释保留）。**Vercel 环境变量需同步更新**，否则线上 500。
2. **`readJsonBody` 吞掉嵌套数组**：`String(v)` 把 `items` 变成 `"[object Object]"`，导致 `JSON.parse` 失败 → 改为 object 类型走 `JSON.stringify(v)`。不要再改回去。
3. **`/api/admin/gallery` 缺 `DELETE`** → 补批量删除（需 moderator 角色 + 清理 Storage 对象）。
4. **`syncAwardCover` 不能挂在 `data` 对象上**（类型推断失败）→ 移到模块级函数。
5. **CSV BOM 断言**：`Response.text()` 会剥离 BOM，必须用 `arrayBuffer()` 查原始字节 `ef bb bf`。
